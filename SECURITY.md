# Security Policy

## Supported releases

Lyra is currently a free Preview/Beta product. Security fixes are provided for the most recent Preview release on a best-effort basis; older Preview artifacts may be withdrawn after a replacement is available. No Stable release is currently supported.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to **x13102306563@gmail.com**. This is the developer's personal email address. All Lyra contact channels currently identify or reach the individual developer rather than a company support team.

Some personal contact channels may be delayed, filtered, unavailable in a particular network environment, or unable to receive certain attachment types. If you do not receive an acknowledgement within seven days, use another contact method listed on [lyra.ltd](https://lyra.ltd) and state that your message is a security report. Do not include secrets in a public issue or discussion.

Please include the affected Lyra version and platform, reproducible steps, impact, relevant logs with personal data removed, and a safe way to contact you. Allow reasonable time for investigation and remediation before public disclosure.

This repository accepts reports about release metadata, installers, signatures, update behavior, and distributed binaries. Product security reports are also welcome at the same address.
